# ICRA 2026 DUET Draft

This directory contains an ICRA-style LaTeX draft for DUET.

Template files were downloaded from Papercept:

- `ieeeconf.zip`: `https://ras.papercept.net/conferences/support/files/ieeeconf.zip`
- `IEEEtranBST.zip`: `https://ras.papercept.net/conferences/support/files/IEEEtranBST.zip`

Build from this directory:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Quantitative experiment results are intentionally marked as `TODO` placeholders.

Figures:

- `figures/duet_teaser.png`: generated with the built-in image generation tool as a text-free scientific teaser.
- `figures/duet_architecture.pdf`: deterministic architecture diagram generated by `make_figures.py`.

Regenerate the architecture figure:

```bash
MPLCONFIGDIR=/tmp/mplconfig python3 make_figures.py
```

Teaser generation prompt summary:

> Create a polished ICRA robotics paper teaser for DUET showing a robot gripper, a teal relative tangent field, an amber absolute state-manifold projection, and a purple gating node. Use a clean scientific style with no text, no logos, and no watermarks.
